1. Notation from the original EIM slides

We use the notation of the original non-affine slides: the source is \(g(x;\mu)\), the basis functions are \(\rho_j\), and the coefficients are \(\gamma_j(\mu)\). The interpolant is \(I_m^x g=\sum_{j=1}^m\gamma_j(\mu)\rho_j\) in \(X_m=\operatorname{span}\{\rho_1,\ldots,\rho_m\}\). The interpolation points \(T_m=\{t^1,\ldots,t^m\}\) are the magic points; here these are spatial positions, not times. The interpolation matrix is \((\mathbb B_m)_{ij}=\rho_j(t^i)\), and its right-hand side has entries \(g(t^i;\mu)\).

\(g(\cdot;\mu_j)\)

S[:, j], computed by source(x, *params[j])

Coefficients returned by interpolation_coefficients

In the slides, \(S_m=\{\mu^1_{\mathrm{EIM}},\ldots,\mu^m_{\mathrm{EIM}}\}\) is the selected parameter set, not the Python snapshot matrix S. A selected snapshot is the generating function \(\xi_{m+1}\); its interpolation residual is \(r_{m+1}=\xi_{m+1}-I_m^x\xi_{m+1}\).

2. E1. Observe and collect source snapshots (5 minutes)

The source \(g(x;c,w)=0.1+\exp(-((x-c)/w)^2)\) depends non-affinely on location and width. Each column of \(S\) is one field on the same 120-point grid. The 27 training parameters and three test parameters are declared separately.

import numpy as np
import matplotlib.pyplot as plt
n = 120
x = np.linspace(0., 1., n)
def source(points, center, width):
    return .1+np.exp(-((np.asarray(points)-center)/width)**2)
params = [(c, w) for c in np.linspace(.2, .8, 9) for w in (.08, .14, .2)]
tests = [(.275, .11), (.425, .17), (.675, .13)]
S = np.column_stack([source(x, *p) for p in params])
illustration_parameters = [(.2, .08), (.5, .08), (.8, .08), (.5, .2)]
illustration_fields = np.column_stack([source(x, *p) for p in illustration_parameters])
print(f'EIM starter: {n} grid points, {S.shape[1]} training fields.')
