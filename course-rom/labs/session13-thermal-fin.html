Practical — Transient thermal fin: POD-greedy, then observations

One thermal-fin notebook, two teaching stages. Start with A — Prediction and POD-greedy after the stationary greedy practical. Stop at its checkpoint for today’s work. B — Sequential observations reuses the same model later, after KF/EnKF; it is not a prerequisite for part A. The historical session-13 URL is retained so existing links and downloads still work.

Download the notebook from the toolbar and thermal-fin-coarse.npz; keep them beside each other. Use the Python environment, including SciPy. The model and solver follow the opening of the original parabolic problem set; this short practical does not reproduce its long derivations or implementation exercises. Read the model notes and the parabolic extension. The full-order solver, prediction API, POD helper and diagnostics are supplied. Focus on the concepts: observe trajectories, compress them, select useful trajectories, and see how errors change with dimension. Only the short adaptive loop is left to implement; detailed certification and filter work are optional reading.

1. A — Prediction and POD-greedy (75 minutes)

1.1. 1. Explore the supplied 2D solver (15 minutes)

There are \(n=1333\) finite-element temperature unknowns. The five material conductivities are fixed at one; the positive Biot number \(Bi\in[0.01,1\)] controls Robin boundary heat loss. The spatial problem is two-dimensional, but the parameter domain here is one-dimensional. With a known zero initial state,

\[M\dot u+A(Bi)u=f\,g(t),\quad A(Bi)=A_0+Bi A_5,\quad A_0=\sum_{q=0}^4 A_q.\]

As in the original exercise, use \(T=10\), \(\Delta t=0.1\) and train with the discrete impulse \(g(t_k)=\delta_{1k}\). The forcing vector is the root-boundary flux load, not a volumetric heat source. The output follows the PDF: \(s(t)=\int_\Omega u(t)\simeq\ell^Tu(t)\), with \(\ell=M\mathbf1\). Divide by the area \(|\Omega|=\mathbf1^TM\mathbf1\) to obtain the spatial mean; this normalization does not change the reduction method. Test another control, \(g(t)=1-\cos t\), at \(Bi=0.05\).

The PDF requests the medium mesh. Here its original coarse matrices (1 333 unknowns) keep the demonstration quick; the same method applies to the medium mesh. The full data archive remains available for later exploration. No mesh-refinement study is required today.

Backward Euler uses the same time grid for full and reduced models:

\[(M+\Delta t A)u^k=Mu^{k-1}+\Delta t f g(t_k),\qquad (M_r+\Delta t A_r)a^k=M_ra^{k-1}+\Delta t f_r g(t_k).\]

Project the mass, both affine stiffness terms, source and output once per basis. For a fixed parameter and time step, factor the time-stepping matrix once per trajectory. The reduced integrator below uses only reduced arrays; reconstructing fields for plotting is separate.

import numpy as np
import matplotlib.pyplot as plt
from pathlib import Path
from scipy.sparse import csc_matrix
from scipy.sparse.linalg import splu
from scipy.linalg import lu_factor, lu_solve
from time import perf_counter

path = Path('thermal-fin-coarse.npz')
if not path.exists(): path = Path('docs/modules/ROOT/attachments/data/thermal-fin-coarse.npz')
if not path.exists(): raise FileNotFoundError('Download thermal-fin-coarse.npz beside this notebook.')
data = np.load(path, allow_pickle=False)
def matrix(name):
    return csc_matrix((data[name+'_data'], data[name+'_indices'], data[name+'_indptr']),
                      shape=tuple(data[name+'_shape']))
M = matrix('M'); Aq = [matrix(f'A{i}') for i in range(6)]
A0 = sum(Aq[:5]); f = data['f']; coordinates = data['coordinates']; n = len(f)
def operator(Bi): return A0+Bi*Aq[5]
dt = .1; steps = 100; times = dt*np.arange(steps+1)
inputs = np.zeros(steps); inputs[0] = 1.  # Original discrete impulse.
prediction_inputs = 1-np.cos(times[1:])
ell = np.asarray(M@np.ones(n))  # PDF output: integral, not area-normalized mean.
area = ell.sum()

def trajectory(Bi, control=None):
    control = inputs if control is None else np.asarray(control)
    solve = splu(M+dt*operator(Bi)).solve
    states = [np.zeros(n)]
    for g in control:
        states.append(solve(M@states[-1]+dt*f*g))
    return np.column_stack(states)

def project_fin(Z):
    return dict(M=Z.T@(M@Z), A0=Z.T@(A0@Z), A5=Z.T@(Aq[5]@Z),
                f=Z.T@f, ell=ell@Z)

def predict_fin(reduced, Bi, control=None):
    control = inputs if control is None else np.asarray(control)
    Mr = reduced['M']; Ar = reduced['A0']+Bi*reduced['A5']
    factor = lu_factor(Mr+dt*Ar)
    propagation = lu_solve(factor, Mr)
    source = lu_solve(factor, dt*reduced['f'])
    a = np.zeros(len(reduced['f'])); coefficients = [a.copy()]
    for g in control:
        a = propagation@a+source*g
        coefficients.append(a.copy())
    return np.column_stack(coefficients)

def mass_rmse(error):
    return float(np.sqrt(np.mean(np.sum(error*(M@error), axis=0))))

def max_mass_error(error):
    return float(np.sqrt(np.maximum(0., np.sum(error*(M@error), axis=0))).max())

train_Bi = np.geomspace(.01, 1., 9)
test_Bi = np.sqrt(train_Bi[:-1]*train_Bi[1:])
print(f'Transient thermal fin: {n} DOFs; impulse training; {steps} time steps.')

1.2. 2. Supplied helpers: compress a trajectory and assess its error (10 minutes)

Use the mass norm for trajectory POD: it measures spatial temperature error. Equal weights \(w_k=\Delta t/T=1/K\) on the noninitial time steps measure the time-mean squared projection error. The known zero initial snapshot need not enter POD.

For certification use a different fixed metric, \(G=A(Bi_{\rm ref})\), \(Bi_{\rm ref}=0.1\). The nonnegative affine components give \(\alpha_{\rm LB}(Bi)=\min(1,Bi/Bi_{\rm ref})\). This is a lower bound relative to \(G\), not relative to \(M\).

The residual includes the time derivative:

\[\rho^k=f g(t_k)-MZ\frac{a^k-a^{k-1}}{\Delta t}-A(Bi)Za^k,\qquad D(Bi)=\left(\frac{\Delta t}{\alpha_{\rm LB}(Bi)} \sum_{k=1}^K(\rho^k)^TG^{-1}\rho^k\right)^{1/2}.\]

Reading only; implementation is supplied. With identical zero initial states, the discrete energy estimate gives \(\max_k\|u_h^k-Za^k\|_M\le D(Bi)\). Indeed each partial residual sum is bounded by the full sum. This is a conservative trajectory certificate, not the stationary residual bound applied independently to each time step. For nonzero initial mismatch, add its squared mass norm under the square root.

Bi_ref = .1
G = operator(Bi_ref)
riesz_solve = splu(G).solve

def scan_fin(Z, parameters):
    reduced = project_fin(Z)
    MZ = M@Z; A0Z = A0@Z; A5Z = Aq[5]@Z
    bounds = []
    for Bi in parameters:
        a = predict_fin(reduced, Bi)
        rho = (f[:, None]*inputs[None, :]
               - MZ@np.diff(a, axis=1)/dt
               - (A0Z+Bi*A5Z)@a[:, 1:])
        representatives = riesz_solve(rho)
        residual_squared = np.maximum(0., np.sum(rho*representatives, axis=0))
        alpha_lb = min(1., Bi/Bi_ref)
        bounds.append(np.sqrt(dt*np.sum(residual_squared)/alpha_lb))
    return np.asarray(bounds)

# scan_fin calls no full-order trajectory. Direct residual/Riesz evaluation
# still depends on n; an offline residual factor is advanced work.
def leading_mass_mode(E):
    # Weighted method of snapshots: w_k=1/steps on this uniform grid.
    correlation = E.T@(M@E)/E.shape[1]
    values, vectors = np.linalg.eigh(correlation)
    if values[-1] <= 1e-24:
        raise ValueError('No resolved trajectory defect remains.')
    return E@vectors[:, -1]/np.sqrt(E.shape[1]*values[-1])

training_trajectories = {}  # Clear if changing the training input or time grid.

def enrich_trajectory(Z, Bi):
    if float(Bi) not in training_trajectories:
        training_trajectories[float(Bi)] = trajectory(Bi)
    states = training_trajectories[float(Bi)][:, 1:]
    defect = states-Z@(Z.T@(M@states))
    v = leading_mass_mode(defect)
    for _ in range(2):
        v -= Z@(Z.T@(M@v))
    norm = np.sqrt(max(0., v@(M@v)))
    if norm <= 1e-10:
        raise ValueError('Dependent enrichment: inspect POD and stopping thresholds.')
    return np.column_stack([Z, v/norm])

1.3. 3. Observe trajectory enrichment and implement POD-greedy (35 minutes)




The outer greedy selects a Biot number. The inner POD selects one missing spatial direction from the entire time trajectory. A selected Biot number may appear again: its trajectory usually contains more than one independent direction. Reuse that cached full trajectory instead of solving it again; count distinct full trajectories separately from enrichments. Thus "one new point" here means one selected trajectory/enrichment, not necessarily a previously unseen parameter.






The following fixed sequence is a recorded example driven by the supplied certificate, with seed \(Bi=0.01\). It makes the diagnostics executable before you implement the selection loop. Reference trajectories for plots are collected separately, after basis construction; they are not inputs to the certificate scan.

def reduced_filter(Z,observations,sensor_ids,ensemble_size=40,seed=131,noise_sd=.005):
    # No truth or full-state reconstruction is used in this online routine.
    rank=Z.shape[1]; Mr=Z.T@(M@Z); Ar=Z.T@(operator(forecast_Bi)@Z)
    F=np.linalg.solve(Mr+dt*Ar,Mr); b=np.linalg.solve(Mr+dt*Ar,dt*(Z.T@f))
    Hr=Z[sensor_ids,:]; R=noise_sd**2*np.eye(len(sensor_ids))
    rng=np.random.default_rng(seed)
    # Known initial state is zero; process noise models imperfect forecasts.
    X=np.zeros((rank,ensemble_size)); a=np.zeros(rank)
    means=[X.mean(axis=1)]; open_loop=[a.copy()]; spreads=[np.zeros(rank)]
    start=perf_counter()
    for g,y in zip(prediction_inputs,observations.T):
        a=F@a+b*g
        X=F@X+b[:,None]*g+.005*rng.standard_normal(X.shape)
        Y=Hr@X
        DX=X-X.mean(axis=1,keepdims=True); DY=Y-Y.mean(axis=1,keepdims=True)
        Cxy=DX@DY.T/(ensemble_size-1); Cyy=DY@DY.T/(ensemble_size-1)
        gain=np.linalg.solve(Cyy+R,Cxy.T).T
        X=X+gain@(y[:,None]+rng.normal(0,noise_sd,Y.shape)-Y)
        means.append(X.mean(axis=1)); spreads.append(X.std(axis=1,ddof=1)); open_loop.append(a.copy())
    return np.array(means).T,np.array(open_loop).T,np.array(spreads).T,perf_counter()-start
