Practical — Certified greedy enrichment

Download the notebook from the toolbar. This practical continues Sampling, basis construction and Galerkin projection: same 1D PDE, two parameters, output and reference metric. There is no new full-order model to learn. NumPy, SciPy and Matplotlib are used; see the Python environment.

Read residual bounds and effectivity, then the greedy algorithm. The supplied code handles prediction, certification and plotting. You implement the selection/enrichment loop. A short, recorded sequence below lets you run and inspect the diagnostics before completing that loop; it is not an answer cell to copy.

1. 1. Reuse the thermal bar and its certificate (10 minutes)

The parameter pair is \(p=(\mu,g)\in[0.1,10\)\times[-0.25,0.25]]. The PDE is \(-\mu u''+u=1\), with \(u(0)=0\) and inward flux \(\mu u'(1)=g\). Its discrete form is

\[A(\mu)u=(\mu K+M)u=b+g e_n,\qquad G=K+M,\qquad s(p)=b^Tu.\]

The output \(s\) is the mean temperature of the unit-length bar. The coercivity lower bound in this fixed reference metric is \(\alpha_{\rm LB}(\mu)=\min(\mu,1)\). The certificate is \(\Delta_G=\sqrt{\rho^TG^{-1}\rho}/\alpha_{\rm LB}\), where \(\rho=b+ge_n-Au_r\). See why min-Theta works. The flux changes the load, not coercivity.

import numpy as np
import matplotlib.pyplot as plt
from scipy.linalg import cho_factor, cho_solve

n = 64
h = 1/n
x = h*np.arange(1, n+1)
K = (2*np.eye(n)-np.eye(n, k=1)-np.eye(n, k=-1))/h
K[-1, -1] = 1/h
weights = np.full(n, h); weights[-1] = h/2
M = np.diag(weights)
b = weights.copy()
e_right = np.eye(n)[:, -1]
G = K+M
G_factor = cho_factor(G)

def full(mu, g):
    return np.linalg.solve(mu*K+M, b+g*e_right)

def append_snapshot(Z, state):
    v = state.copy()
    for _ in range(2):
        v -= Z@(Z.T@G@v)
    norm = np.sqrt(max(0., v@G@v))
    if norm <= 1e-11*max(1., np.sqrt(state@G@state)):
        raise ValueError('Dependent enrichment: inspect tolerance and certificate.')
    return np.column_stack([Z, v/norm])

def project(Z):
    return Z.T@K@Z, Z.T@M@Z, Z.T@b, Z.T@e_right

def scan(Z, pairs):
    # Reduced operators are assembled once per basis, not once per parameter.
    Kr, Mr, br, er = project(Z)
    states = []
    for mu, g in pairs:
        a = np.linalg.solve(mu*Kr+Mr, br+g*er)
        states.append(Z@a)
    states = np.column_stack(states)
    residuals = np.column_stack([
        b+g*e_right-(mu*K+M)@ur
        for (mu, g), ur in zip(pairs, states.T)])
    representatives = cho_solve(G_factor, residuals)
    dual_norms = np.sqrt(np.maximum(0., np.sum(residuals*representatives, axis=0)))
    bounds = dual_norms/np.minimum(pairs[:, 0], 1.)
    return states, bounds

# No full solves in scan. Its direct Riesz solves/reconstruction still cost n.
mu_train = np.geomspace(.1, 10., 15)
mu_test = np.sqrt(mu_train[:-1]*mu_train[1:])
training = {
    '1 parameter: g=0': np.array([(mu, 0.) for mu in mu_train]),
    '2 parameters': np.array([(mu, g) for mu in mu_train
                             for g in (-.25, 0., .25)])}
validation = {
    '1 parameter: g=0': np.array([(mu, 0.) for mu in mu_test]),
    '2 parameters': np.array([(mu, g) for mu in mu_test
                             for g in (-.125, .125)])}
print('Same thermal bar: G=K+M; one- and two-parameter experiments ready.')

def energy_errors(pairs, errors):
    return np.array([np.sqrt(max(0., e@(mu*K+M)@e))
                     for (mu, g), e in zip(pairs, errors.T)])

def inspect_sequence(pairs, test_pairs, sequence):
    bases = []; train_predictions = []; certificates = []
    Z = np.empty((n, 0))
    for pair in sequence:
        Z = append_snapshot(Z, full(*pair))
        ur, bound = scan(Z, pairs)
        bases.append(Z.copy()); train_predictions.append(ur); certificates.append(bound)
    # Reference solves are separate from the construction/selection experiment.
    truth = np.column_stack([full(*p) for p in pairs])
    test_truth = np.column_stack([full(*p) for p in test_pairs])
    rows = []
    for Z, ur, bound in zip(bases, train_predictions, certificates):
        test_ur, _ = scan(Z, test_pairs)
        error = truth-ur
        error_G = np.sqrt(np.maximum(0., np.sum(error*(G@error), axis=0)))
        effectivity = np.divide(bound, error_G, out=np.full_like(bound, np.nan),
                                where=error_G > 1e-9)
        rows.append(dict(rank=Z.shape[1], train=energy_errors(pairs, error),
                         test=energy_errors(test_pairs, test_truth-test_ur),
                         bound=bound, error_G=error_G, effectivity=effectivity,
                         output=np.abs(b@(test_truth-test_ur))))
    return dict(bases=bases, rows=rows, selected=np.asarray(sequence))

For nested Galerkin spaces and this SPD operator, the error in the parameter-dependent energy norm \(\|e\|_{a_\mu}\) cannot increase at a fixed parameter. Its maximum over the same finite set therefore cannot increase either. The fixed-norm certificate is a different quantity: it need not decrease at every step. Neither curve guarantees accuracy over the entire continuous parameter domain.

2.1. Sweep the parameters at a fixed basis dimension

The rank plot above answers "what happens when the basis grows?" Now hold a basis fixed and sweep the parameters. Plot the true fixed-norm error and its matching certificate together:

\[e_N(p)=\|u_h(p)-u_N(p)\|_G,\qquad \Delta_N(p)=\frac{\|R_N(p)\|_{V_h'}}{\alpha_{\mathrm{LB}}(\mu)}.\]

Solid and dashed curves of the same colour refer to the same dimension \(N\). We use \(N\) here for the reduced dimension, denoted \(r\) in the code. The certificate should lie above the true error point by point; comparing the energy error with this fixed-norm certificate would mix norms.

  • One parameter: sweep \(\mu\) logarithmically, keeping \(g=0\), and explicitly insert every exact snapshot parameter. A uniform grid alone generally misses these values.

  • Two parameters, paired sweep: sweep the full diffusivity interval at each of five flux levels \(g=-0.25,-0.125,0,0.125,0.25\). Insert every selected diffusivity and flux value exactly. Display the resulting parameter pairs in separate flux blocks on one horizontal axis, with gaps between blocks. Bottom ticks show diffusivity; labels above each block give its flux. The same sweep pairs are used at every dimension. This probes both parameters instead of only joining the selected snapshots.

At dimension \(N\), the first \(N\) selected snapshots belong to the reduced space. Galerkin therefore reproduces their full solutions exactly in exact arithmetic, by uniqueness of the coercive problem. Their error and residual should be zero up to roundoff. Mark only the snapshots already included at that dimension; future enrichment points need not yet have zero error. This snapshot-reproduction property need not survive a subsequent POD truncation.

A logarithmic vertical axis cannot show exact zero. Values below the stated display floor are drawn on its line; the unmodified numerical errors at snapshot parameters are printed below. No computed error is replaced by zero.

The full solutions are references for these plots only; they do not participate in greedy selection. The bases are already fixed before the sweep is evaluated.

2.1.1. Compute the errors and certificates

Certificate implementation: direct, full-dimensional Riesz evaluation. The supplied scan computes \(\rho=b+ge_n-(\mu K+M)Za\), solves \(Gz_R=\rho\), and returns \(\Delta_N=\sqrt{\rho^Tz_R}/\min(\mu,1)\). The reduced prediction uses affine projected operators, but the certificate here does not use an offline affine residual factor. Its residual formation and Riesz solves still depend on \(n\). The offline residual factor is optional advanced reading.

Run this cell when changing the bases, ranks or sweep pairs. It stores the numerical arrays without plotting. Full reference solutions are used only to measure true errors; they are not needed for \(\Delta_N\) or greedy selection.

def snapshot_sweeps(selected_1d, selected_2d, points_per_sweep=101):
    # Exact snapshot values are inserted, not rounded to nearest grid nodes.
    base_mu = np.geomspace(.1, 10., points_per_sweep)
    mu_1d = np.unique(np.r_[base_mu, np.asarray(selected_1d)[:, 0]])
    mu_2d = np.unique(np.r_[base_mu, np.asarray(selected_2d)[:, 0]])
    fluxes = np.unique(np.r_[np.linspace(-.25, .25, 5), np.asarray(selected_2d)[:, 1]])
    pairs_1d = np.column_stack([mu_1d, np.zeros_like(mu_1d)])
    pairs_2d = []; coordinates = []; blocks = []
    for j, g in enumerate(fluxes):
        start = j*len(mu_2d); stop = start+len(mu_2d)
        local = (np.log10(mu_2d)+1)/2
        horizontal = 1.3*j+local
        pairs_2d.append(np.column_stack([mu_2d, np.full_like(mu_2d, g)]))
        coordinates.append(horizontal)
        blocks.append(dict(g=float(g), start=start, stop=stop,
                           left=float(horizontal[0]), right=float(horizontal[-1])))
    pairs = {'1 parameter: g=0': pairs_1d, '2 parameters': np.vstack(pairs_2d)}
    return pairs, np.concatenate(coordinates), blocks

def compute_sweep_results(runs, parameter_pairs, ranks):
    results = {}
    for name, pairs in parameter_pairs.items():
        truth = np.column_stack([full(*pair) for pair in pairs])
        results[name] = {}
        for rank in ranks:
            basis = runs[name]['bases'][rank-1]
            prediction, delta = scan(basis, pairs)
            error = truth-prediction
            true_error = np.sqrt(np.maximum(0., np.sum(error*(G@error), axis=0)))
            selected = runs[name]['selected'][:rank]
            indices = np.array([np.flatnonzero(np.all(pairs == pair, axis=1))[0]
                                for pair in selected])
            results[name][rank] = dict(error=true_error, delta=delta, snapshot_indices=indices)
    return results
