= Session 3 — A posteriori estimation and effectivity
:navtitle: 3 · Error estimation

*Two-hour cours intégré · explanation, derivation and Python practical*

By the end, you should be able to compute a residual dual norm, state the stability assumption behind an error bound, verify coverage and interpret effectivity.
An error certificate assesses the reduced approximation to a specified model; it does not replace validation against observations.

== Prepare

Review xref:sessions/02-galerkin-pod.adoc[session 2]. Read xref:rom::foundations/riesz.adoc[the Hilbert-space and Riesz introduction] through the matrix example, then xref:rom::certification/residual-bound.adoc[the residual-bound notes] through the bounds summary.
The estimator offline/online factorization is optional advanced reading. Affine offline/online prediction remains required material from session 2.
The practical is self-contained, so unfinished modifications to your previous notebook will not prevent you from starting.
