= Session 2 — From snapshot bases to POD
:navtitle: 2 · Snapshot bases, then POD
:stem: latexmath

*Cours intégré · explanations and continuation of the same Python practical*

The course route is *sample → construct a basis → project with Galerkin → compress with POD*.
POD introduces a new way to construct the reduced space; the physical model and prediction code remain the same.

== First stage — Sampling and Galerkin

Use the xref:rom::reduction/galerkin.adoc[Reduced bases and Galerkin notes] and the xref:labs/galerkin-sampling.adoc[sampling/Galerkin practical].
The model is a 1D thermal bar with diffusivity and right-endpoint flux as parameters. Keep the fixed reference-energy metric stem:[G=K+M] and the mean-temperature output.

Complete the structured/random sampling, snapshot orthonormalization and Galerkin projection. The residual and conditioning tasks can be studied with these snapshot bases: they do not require POD.
For certification, read xref:rom::certification/residual-bound.adoc[Residual bounds and effectivity] and xref:rom::certification/coercivity-lower-bound.adoc[the coercivity lower bound].

== Next stage — Understand and use POD

Start with the xref:rom::reduction/pod.adoc[POD notes: from SVD to parametrized PDE snapshots]. Read through *Use the POD basis in your Galerkin practical*; the later sections are optional reading.
The executed Python example computes thermal snapshots, constructs Euclidean and energy POD bases, reconstructs the profiles and reports training errors by rank. Recall the PCA studied in S1, but keep uncentered snapshots for this first ROM experiment.

Then download or reopen xref:labs/galerkin-sampling.adoc#pod-continuation[the same practical notebook, section 4]. Use your existing snapshots and Galerkin functions; replace only the construction of stem:[Z].

== Checkpoint

Bring a rank/error table and one plot for the same held-out pairs used previously.
Explain why orthonormalization preserves a snapshot span while rank-truncated POD usually changes it, and why a small training tail is not a prediction certificate.
Identify which computations are offline and which are needed for a new scalar-output prediction.
