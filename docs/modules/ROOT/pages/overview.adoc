= Build and publishing
:navtitle: Build and publishing

== Course and reference components

`docs/` contains the M2 course route; `materials/` contains the broader reference library.
Both are assembled by the root `site.yml` using the Feel++ Antora UI.
Students should begin at the xref:index.adoc[course home] and xref:setup.adoc[notebook setup].

== Build the website and executable practical

Use Node.js 22 or newer and Python 3.12 or newer.
From the repository root:

[source,bash]
----
npm ci
python3 -m venv .venv-course
source .venv-course/bin/activate
python -m pip install -r requirements-course.txt
npm run antora
python scripts/verify-session01.py
python scripts/verify-course-site.py
npm start
----

The selected practical is authored as AsciiDoc with `:page-jupyter: true` and `:dynamic-blocks:`.
The Feel++ Antora Jupyter extension generates notebooks in the content catalog; the Feel++ AsciiDoc extension executes opted-in Python blocks during HTML generation.
Historical dynamic examples and notebook exports are not enabled globally.
Only the release pages selected in `site.yml` are exported. A generated manifest records their sources, hashes and metadata.

The documentation workflow verifies the course before publishing the artifact to the existing GitHub Pages branch on `master`.
No local Dropbox source path is needed to build this release.

== How to build the project

You need first to follow the xref:quickstart.adoc[quickstart] to get the {feelpp} environment.
The installation procedure uses xref:env/cmake.adoc[Cmake] for the {cpp} programs and create a bundle of this project.
The steps are as follows:

[source,bash]
----
$ cmake --preset default # <1>
$ cmake --build --preset default # <2>
$ cmake --build --preset default -t install # <3>
$ ctest --preset default # <4>
$ cmake --build --preset default -t package # <5>
----
<1> Configure the project
<2> Build the project
<3> Install the project
<4> Run the tests
<5> Package the project
