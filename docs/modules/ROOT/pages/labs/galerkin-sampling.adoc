== 1. Explore the supplied 1D model with two parameters (10 minutes)

Think of stem:[u] as a dimensionless temperature rise along a thin bar: diffusion spreads heat, the stem:[+u] term represents distributed heat loss, and the constant right-hand side represents uniform heating. Consider stem:[-\mu u''+u=1] on stem:[(0,1)] with stem:[u(0)=0] and stem:[\mu u'(1)=g]. Here stem:[\mu>0] is diffusivity and stem:[g] is the *inward flux imposed at the right endpoint*. Thus the parameter is stem:[p=(\mu,g)]; changing the flux changes the load, while changing diffusivity changes the operator.

Use stem:[n=64] piecewise-linear elements of length stem:[h=1/n]. The code supplies the stiffness stem:[K], a lumped mass matrix stem:[M], the source load stem:[b], and the right-endpoint load stem:[e_n]. Choose the reference diffusivity stem:[\bar\mu=1]. The discrete model and the *fixed reference-energy scalar product* are

[stem]
++++
(\mu K+M)\mathbf u=b+g e_n,\qquad
G=A(\bar\mu)=\bar\mu K+M=K+M,\qquad
(v,w)_G=v^TGw,\quad \|v\|_G=\sqrt{v^TGv}.
++++

The reference parameter is fixed before any new prediction: stem:[G] is *not* recomputed at each stem:[\mu]. This norm measures both diffusion energy and the reaction contribution. It is the norm used below for orthonormalization, POD and the residual bound.
The *output of interest* is the mean temperature rise along the whole bar,

[stem]
++++
s(\mu,g)=\frac{1}{1-0}\int_0^1u(x;\mu,g)\,dx
\ \approx\ b^T\mathbf u(\mu,g).
++++

Because the bar has unit length, its integral and mean have the same numerical value. This global output differs from the endpoint temperature stem:[u(1)], which is especially sensitive to the imposed flux. The endpoint has half a cell's mass; retaining that weight makes the weak-form model and the output consistent. The source load is stem:[b=M\mathbf 1]. This model remains a small teaching calculation, not a high-fidelity PDE discretization study.

[source%dynamic%open,python,fail-on-error=true,output=matplotlib,figure-alt="Two-panel comparison of one-dimensional full-order states varying diffusivity and right-endpoint flux separately"]
----
import numpy as np
import matplotlib.pyplot as plt

n = 64
h = 1.0 / n
x = h * np.arange(1, n + 1)
K = (2*np.eye(n) - np.eye(n, k=1) - np.eye(n, k=-1)) / h
K[-1, -1] = 1.0 / h  # Natural condition at x=1.
weights = np.full(n, h)
weights[-1] = h / 2
M = np.diag(weights)
b = weights.copy()    # Integral of the unit source against basis functions.
e_right = np.eye(n)[:, -1]
mu_bar = 1.0
G = mu_bar*K + M

def full(mu, g):
    """Full solve supplied for collecting snapshots and checking predictions."""
    return np.linalg.solve(mu*K + M, b + g*e_right)

def output(u):
    """Approximate mean temperature rise over the unit-length bar."""
    return float(b @ u)

fig, axes = plt.subplots(1, 2, figsize=(10, 3.5), sharey=True)
for mu in (0.1, 1.0, 10.0):
    axes[0].plot(x, full(mu, 0.0), label=f"mu={mu:g}")
for g in (-0.25, 0.0, 0.25):
    axes[1].plot(x, full(1.0, g), label=f"g={g:g}")
axes[0].set(xlabel="Position x", ylabel="State u(x)",
            title="Vary diffusivity; g=0")
axes[1].set(xlabel="Position x", title="Vary right flux; mu=1")
for ax in axes:
    ax.legend()
fig.tight_layout()
plt.show()
print(f"1D two-parameter full model: n={n}, h={h:.6f}")
----
