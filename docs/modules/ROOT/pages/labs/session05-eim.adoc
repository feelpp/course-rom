== Notation from the original EIM slides

We use the notation of xref:attachment$lecture-rbobm-beamer-non-affine.pdf[the original non-affine slides]: the source is stem:[g(x;\mu)], the basis functions are stem:[\rho_j], and the coefficients are stem:[\gamma_j(\mu)].
The interpolant is stem:[I_m^x g=\sum_{j=1}^m\gamma_j(\mu)\rho_j] in stem:[X_m=\operatorname{span}\{\rho_1,\ldots,\rho_m\}].
The interpolation points stem:[T_m=\{t^1,\ldots,t^m\}] are the *magic points*; here these are spatial positions, not times.
The interpolation matrix is stem:[(\mathbb B_m)_{ij}=\rho_j(t^i)], and its right-hand side has entries stem:[g(t^i;\mu)].

[cols="1,2",options="header"]
|===
|Course notation |Python representation
|stem:[g(\cdot;\mu_j)] |`S[:, j]`, computed by `source(x, *params[j])`
|Basis functions stem:[\rho_j] |Columns of `rho`
|Magic points stem:[t^i] |`x[points]`; `points` stores grid indices
|stem:[\mathbb B_m] |`B_eim = rho[points, :]`
|stem:[\gamma(\mu)] |Coefficients returned by `interpolation_coefficients`
|===

In the slides, stem:[S_m=\{\mu^1_{\mathrm{EIM}},\ldots,\mu^m_{\mathrm{EIM}}\}] is the selected *parameter set*, not the Python snapshot matrix `S`.
A selected snapshot is the *generating function* stem:[\xi_{m+1}]; its interpolation residual is stem:[r_{m+1}=\xi_{m+1}-I_m^x\xi_{m+1}].

== E1. Observe and collect source snapshots (5 minutes)

The source stem:[g(x;c,w)=0.1+\exp(-((x-c)/w)^2)] depends non-affinely on location and width. Each column of stem:[S] is one field on the same 120-point grid. The 27 training parameters and three test parameters are declared separately.

[source%dynamic%open,python,fail-on-error=true]
----
import numpy as np
import matplotlib.pyplot as plt
n = 120
x = np.linspace(0., 1., n)
def source(points, center, width):
    return .1+np.exp(-((np.asarray(points)-center)/width)**2)
params = [(c, w) for c in np.linspace(.2, .8, 9) for w in (.08, .14, .2)]
tests = [(.275, .11), (.425, .17), (.675, .13)]
S = np.column_stack([source(x, *p) for p in params])
illustration_parameters = [(.2, .08), (.5, .08), (.8, .08), (.5, .2)]
illustration_fields = np.column_stack([source(x, *p) for p in illustration_parameters])
