POD compresses the solution snapshots you computed in the xref:course-rom::labs/galerkin-sampling.adoc[sampling/Galerkin practical]. We keep the same parametrized PDE. We first reconstruct its training solutions with fewer directions, then use those directions in the Galerkin solver you already know.

[[pde-snapshots]]
== 1. Compute solution snapshots of the parametrized PDE

Consider the thermal bar from the practical:

[stem]
++++
-\mu u''+u=1\quad\text{on }(0,1),\qquad
u(0)=0,\qquad \mu u'(1)=g.
++++

Diffusivity stem:[\mu] changes the operator; the inward right-endpoint flux stem:[g] changes the load. The discrete equations are

[stem]
++++
(\mu K+M)\mathbf u(\mu,g)=b+g e_n,
\qquad (\mu,g)\in[0.1,10]\times[-0.25,0.25].
++++

[[snapshots]]
Pick several parameter pairs and solve the full model once for each. A *snapshot* is one of these solution vectors. Store them as columns of stem:[S\in\mathbb R^{n\times m}]: rows are spatial unknowns and columns are sampled solutions.

Here we use 32 elements to keep the demonstration small, six diffusivities and three fluxes: stem:[m=18] snapshots. Your practical can keep its original mesh and sampling designs.

[source%dynamic%open,python,fail-on-error=true,output=matplotlib,figure-alt="Eighteen solution snapshots of the one-dimensional thermal PDE, obtained by varying diffusivity and endpoint flux",figure-caption="Each curve is one full-order solution. POD will approximate this collection with a few shared spatial directions."]
----
import numpy as np
import matplotlib.pyplot as plt

n = 32
h = 1.0 / n
x = h * np.arange(1, n + 1)
K = (2*np.eye(n) - np.eye(n, k=1) - np.eye(n, k=-1)) / h
K[-1, -1] = 1.0 / h
mass_weights = np.full(n, h)
mass_weights[-1] = h / 2
M = np.diag(mass_weights)
f_source = mass_weights.copy()
e_right = np.eye(n)[:, -1]
G = K + M  # Fixed reference energy at mu_bar = 1.

parameters = [(mu, g) for mu in np.geomspace(0.1, 10, 6)
              for g in (-0.25, 0.0, 0.25)]
S = np.column_stack([
    np.linalg.solve(mu*K + M, f_source + g*e_right)
    for mu, g in parameters
])
m = S.shape[1]
fig, ax = plt.subplots(figsize=(7, 3.5))
for snapshot in S.T:
    ax.plot(np.r_[0, x], np.r_[0, snapshot], alpha=0.6)
ax.set(xlabel='Position x', ylabel='Temperature rise', title=f'{m} training snapshots')
ax.grid(alpha=0.25)
plt.show()
print(f'Thermal snapshot matrix: {S.shape[0]} spatial unknowns x {m} sampled solutions')
----

These profiles are different, but they share much of their shape. Instead of keeping one direction for every independent snapshot, can we retain only two or three directions?

[[svd-foundations]]
== 2. What does the SVD do to these snapshots?

Write the snapshot matrix as stem:[S=U\Sigma V^T]. The columns of stem:[U] are common spatial directions, the singular values in stem:[\Sigma] measure their contributions, and stem:[\Sigma V^T] gives their coefficients in each snapshot. For snapshot stem:[j],

[stem]
++++
\mathbf u_j=\sum_i\sigma_i V_{ji}U_{:,i}.
++++

Keep only the first stem:[r] directions, associated with the largest singular values. With stem:[Z=U_{:,1:r}], the approximate snapshot is

[stem]
++++
\mathbf u_j\approx Zc_j,\qquad c_j=Z^T\mathbf u_j.
++++

A single direction gives a common profile multiplied by a different number for every snapshot. Two directions allow two independent contributions, and so on. The discarded components determine the reconstruction error.

[[pca-bridge]]
This recalls PCA from S1: observations are now PDE solutions, stored in columns rather than rows. We do *not* subtract the mean in this first experiment: we approximate full states, not fluctuations around their mean.

[[pod-algorithm]]
=== POD algorithm for these thermal snapshots — Euclidean norm

For a fixed rank stem:[r], the first left singular vectors minimize the *mean squared Euclidean reconstruction error* of these sampled PDE solutions.

[.pseudocode]
....
\begin{algorithm}
\caption{POD of the parametrized thermal solutions}
\begin{algorithmic}
\INPUT Parameter pairs $(\mu_j,g_j)$, thermal matrices $K,M$, loads $b,e_n$, rank $r$
\FOR{$j=1$ \TO $m$}
  \STATE Solve $(\mu_jK+M)u_j=b+g_je_n$ and store column $S_{:,j}=u_j$
\ENDFOR
\STATE Compute the economy SVD $S/\sqrt m=U\Sigma V^T$
\STATE Retain resolved directions $Z=U_{:,1:r}$
\STATE Reconstruct training snapshots $\widehat S=Z(Z^TS)$
\STATE Training RMS error $=\sqrt{\sum_{i>r}\sigma_i^2}$
\OUTPUT Basis $Z$ and training reconstruction error
\end{algorithmic}
\end{algorithm}
....

[source%dynamic%open,python,fail-on-error=true]
----
U, sigma, Vt = np.linalg.svd(S / np.sqrt(m), full_matrices=False)
r = 2
Z_euclidean = U[:, :r]
S_euclidean = Z_euclidean @ (Z_euclidean.T @ S)
rms_euclidean = np.linalg.norm(S - S_euclidean, 'fro') / np.sqrt(m)
tail_euclidean = np.sqrt(np.sum(sigma[r:]**2))
assert np.allclose(Z_euclidean.T @ Z_euclidean, np.eye(r))
assert np.isclose(rms_euclidean, tail_euclidean, rtol=1e-7, atol=1e-12)
print(f'Euclidean POD, rank {r}: measured training RMS={rms_euclidean:.6e}, '
      f'SVD tail={tail_euclidean:.6e}')
----

This is ordinary POD. It treats the state coordinates with the Euclidean norm. To keep the energy norm from your practical, we must change the coordinates used for the SVD.

[[weighted-svd]]
== 3. Keep the reference-energy norm from the practical

Our practical uses stem:[\|v\|_G^2=v^TGv] with the fixed matrix stem:[G=K+M]. It measures diffusion and reaction contributions at stem:[\bar\mu=1]. This is the norm used for orthonormalizing your previous snapshot basis.

POD must minimize reconstruction error in that *same* norm. The projection coefficients are now stem:[c_j=Z^TG\mathbf u_j], and we require stem:[Z^TGZ=I_r].

Factor stem:[G=LL^T] with NumPy's Cholesky convention. Since stem:[\|v\|_G=\|L^Tv\|_2], applying SVD to stem:[L^TS/\sqrt m] finds the best directions in energy coordinates. Solve stem:[L^TZ=U_{:,1:r}] to express them back as physical state vectors.

[[weighted-pod-algorithm]]
=== Weighted POD algorithm for these thermal snapshots

The state metric weights space; snapshot weights stem:[w_j] specify the importance of each parameter pair. Here stem:[w_j=1/m]: all pairs have equal importance. Choosing weights that sum to one gives a mean squared error.

[.pseudocode]
....
\begin{algorithm}
\caption{Thermal snapshot POD in the reference-energy norm}
\begin{algorithmic}
\INPUT Thermal snapshots $S=[u(\mu_1,g_1),\ldots,u(\mu_m,g_m)]$, $G=K+M$, weights $w_j>0$, rank $r$
\STATE Factor $G=LL^T$ and form $W=\operatorname{diag}(w_1,\ldots,w_m)$
\STATE Transform snapshots $Y=L^TSW^{1/2}$
\STATE Compute the economy SVD $Y=U\Sigma V^T$
\STATE Solve $L^TZ=U_{:,1:r}$ for the retained resolved directions
\STATE Reconstruct $\widehat S=Z(Z^TGS)$
\STATE Weighted training error $=\sqrt{\sum_{i>r}\sigma_i^2}$
\OUTPUT Basis $Z$ with $Z^TGZ=I_r$, and training reconstruction error
\end{algorithmic}
\end{algorithm}
....

[source%dynamic%open,python,fail-on-error=true,output=matplotlib,figure-alt="First two reference-energy POD modes and rank-two reconstructions of three thermal training solutions",figure-caption="Two common POD modes reconstruct three different thermal solutions. Dashed profiles are reconstructions of known snapshots, not new Galerkin predictions."]
----
L = np.linalg.cholesky(G)
Y = L.T @ S / np.sqrt(m)
Ug, sigma_g, Vtg = np.linalg.svd(Y, full_matrices=False)
Z = np.linalg.solve(L.T, Ug[:, :r])
coefficients = Z.T @ G @ S
S_pod = Z @ coefficients
E = S - S_pod
rms_energy = np.sqrt(np.sum(E * (G @ E)) / m)
tail_energy = np.sqrt(np.sum(sigma_g[r:]**2))
assert np.allclose(Z.T @ G @ Z, np.eye(r))
assert np.isclose(rms_energy, tail_energy, rtol=1e-7, atol=1e-12)
print(f'Energy POD, rank {r}: measured training RMS={rms_energy:.6e}, '
      f'SVD tail={tail_energy:.6e}')

fig, axes = plt.subplots(1, 2, figsize=(10, 3.5))
for i in range(r):
    axes[0].plot(np.r_[0, x], np.r_[0, Z[:, i]], label=f'Mode {i+1}')
for j in (0, 7, 17):
    mu, g = parameters[j]
    curve, = axes[1].plot(np.r_[0, x], np.r_[0, S[:, j]], label=f'mu={mu:.2g}, g={g:g}')
    axes[1].plot(np.r_[0, x], np.r_[0, S_pod[:, j]], '--', color=curve.get_color())
axes[0].set(xlabel='Position x', ylabel='Mode amplitude', title='Common POD directions')
axes[1].set(xlabel='Position x', ylabel='Temperature rise', title=f'Snapshots and rank-{r} reconstructions')
for ax in axes:
    ax.legend(fontsize=8)
    ax.grid(alpha=0.25)
plt.show()
----

Modes are directions, not temperature solutions: negative amplitudes are allowed, and reversing a mode's sign reverses its coefficients without changing the reconstruction. All snapshots use the *same* modes with different coefficients.

[[pod-first-mode]]
=== Why does POD choose these directions?

For a normalized direction stem:[z], the best coefficient for snapshot stem:[u_j] is stem:[z^TGu_j]. Its projected component and residual are orthogonal in the stem:[G] inner product. Pythagoras therefore gives

[stem]
++++
\underbrace{\|u_j\|_G^2}_{\text{total}}
=\underbrace{(z^TGu_j)^2}_{\text{captured}}
+\underbrace{\|u_j-z(z^TGu_j)\|_G^2}_{\text{discarded}}.
++++

Averaging over the training snapshots keeps the total fixed. *Minimizing discarded energy is therefore equivalent to maximizing captured energy.* SVD orders the directions by their contributions: the first captures the most, the second captures the most among directions orthogonal to the first, and so on. The optional derivation below explains each step of this argument.

[[rank-validation]]
== 4. Measure training error and choose a rank

[[pod-tail]]
For our 18 equally weighted snapshots, define the training RMS in the reference-energy norm:

[stem]
++++
E_r=\sqrt{\frac1m\sum_{j=1}^m\|u_j-ZZ^TGu_j\|_G^2}
=\sqrt{\sum_{i>r}\sigma_{G,i}^2}.
++++

The stem:[\sigma_{G,i}] are the singular values of stem:[L^TS/\sqrt m]. Increasing stem:[r] retains more directions and decreases this reconstruction error. Dividing by the RMS norm of the snapshots gives a relative error.

The following table computes both the actual projection error and the SVD prediction for several ranks. Each pair should agree. The plot compares relative training errors for the Euclidean and reference-energy objectives; each curve uses its own norm.

[source%dynamic%open,python,fail-on-error=true,output=matplotlib,figure-alt="Relative thermal snapshot training RMS versus POD rank in the Euclidean and reference-energy norms",figure-caption="A larger rank decreases training reconstruction error. Euclidean and energy POD optimize different norms; their relative curves do not compare errors in one common metric."]
----
total_euclidean = np.linalg.norm(S, 'fro') / np.sqrt(m)
total_energy = np.sqrt(np.sum(S * (G @ S)) / m)
rank_list = np.arange(1, 7)
relative_euclidean, relative_energy = [], []
print('rank | Euclidean RMS / tail | energy RMS / tail | relative energy RMS')
for rank in rank_list:
    Ze = U[:, :rank]
    Ee = S - Ze @ (Ze.T @ S)
    err_e = np.linalg.norm(Ee, 'fro') / np.sqrt(m)
    Zg = np.linalg.solve(L.T, Ug[:, :rank])
    Eg = S - Zg @ (Zg.T @ G @ S)
    err_g = np.sqrt(np.sum(Eg * (G @ Eg)) / m)
    predicted_e = np.sqrt(np.sum(sigma[rank:]**2))
    predicted_g = np.sqrt(np.sum(sigma_g[rank:]**2))
    assert np.isclose(err_e, predicted_e, rtol=1e-7, atol=1e-12)
    assert np.isclose(err_g, predicted_g, rtol=1e-7, atol=1e-12)
    relative_euclidean.append(err_e / total_euclidean)
    relative_energy.append(err_g / total_energy)
    print(f'{rank:4d} | {err_e:.6e} / {predicted_e:.6e} | '
          f'{err_g:.6e} / {predicted_g:.6e} | {err_g / total_energy:.3%}')
print('Verified: thermal training errors match the singular-value tails.')

tolerance = 0.01  # Target 1% relative training RMS.
relative_tails = np.sqrt(np.r_[np.cumsum((sigma_g**2)[::-1])[::-1], 0.0]
                         / np.sum(sigma_g**2))
chosen_rank = int(np.flatnonzero(relative_tails <= tolerance)[0])
print(f'Energy POD: smallest rank for {tolerance:.0%} relative training RMS = {chosen_rank}')
fig, ax = plt.subplots(figsize=(7, 3.5))
ax.semilogy(rank_list, relative_euclidean, 'o-', label='Euclidean POD, Euclidean error')
ax.semilogy(rank_list, relative_energy, 's--', label='Energy POD, G-error')
ax.axhline(tolerance, color='black', linestyle=':', label='1% target')
ax.set(xlabel='Retained rank', ylabel='Relative training RMS', xticks=rank_list)
ax.legend(fontsize=8)
ax.grid(alpha=0.25)
plt.show()
----

For the default training set, two energy POD modes give about *7.16%* relative training RMS. Three give *1.07%*, just above the 1% target; four give *0.076%*, so the selected rank is four. These numbers describe these 18 sampled solutions, not a guarantee over all parameter pairs. Rerun the cells to obtain new results after changing the sampling.

Use an error target, rather than choosing a rank only because it looks small. A 1% relative RMS target requires a squared-tail fraction at most stem:[10^{-4}]: keeping 99% of energy only guarantees 10% relative RMS error.

Do not retain directions associated with singular values below numerical precision merely to request a larger rank. All computed singular values contribute to the reported tail, even those too small to define reliable modes.

== 5. Use this basis for Galerkin predictions in your TP

So far, we reconstructed *known training snapshots*. At a new pair stem:[(\mu,g)], the full solution is unavailable. Galerkin obtains coefficients by solving the reduced equations:

[stem]
++++
(\mu K_r+M_r)a=b_r+g e_r,
\qquad
K_r=Z^TKZ,\quad M_r=Z^TMZ,\quad b_r=Z^Tb,\quad e_r=Z^Te_n.
++++

These are the equations from your previous TP. Only the construction and dimension of stem:[Z] change. The mean-temperature output remains stem:[s_r=(Z^Tb)^Ta]. Project matrices and loads offline; solve the small system and evaluate the projected output online.

.Detailed derivation — projection, captured energy and optimal POD modes
======
[[pod-energy-proof]]

*Why the first POD mode maximizes captured energy*


We want to replace every snapshot by a multiple of *one common direction*. There are two choices to make: the direction stem:[z], and one coefficient stem:[c_j] for each snapshot. First solve the coefficient problem for a fixed direction; then choose the direction that best represents the whole collection.

Here stem:[(v,w)_G=v^TGw], with stem:[G] symmetric positive definite. Normalize stem:[z] by stem:[z^TGz=1]: this fixes its scale, so that changing a coefficient really changes the reconstruction rather than merely compensating for a rescaling of the direction.


*1. For a fixed direction, find the best coefficient*


For snapshot stem:[u_j], minimize the squared distance to stem:[c z]:

[stem]
++++
\phi_j(c)=\|u_j-cz\|_G^2
=(u_j-cz)^TG(u_j-cz)
=\|u_j\|_G^2-2c\,z^TGu_j+c^2.
++++

Only the last two terms depend on stem:[c]. Differentiating gives

[stem]
++++
\phi_j'(c)=-2z^TGu_j+2c=0
\quad\Longrightarrow\quad c_j=z^TGu_j.
++++

Since stem:[\phi_j''(c)=2>0], this is the unique minimizing coefficient. Thus the best reconstruction along this fixed direction is stem:[p_j=c_j z=z(z^TGu_j)]. Without normalization, the minimizing coefficient would be stem:[(z^TGu_j)/(z^TGz)].

The remaining component stem:[e_j=u_j-p_j] is orthogonal to the direction *in the chosen metric*:

[stem]
++++
z^TGe_j=z^TGu_j-c_jz^TGz=c_j-c_j=0.
++++

This is a projection of an already available snapshot. The coefficients are not yet those of a Galerkin prediction at a new parameter.


*2. Split each snapshot into captured and discarded energy*


Write stem:[u_j=p_j+e_j]. Expanding its squared norm gives

[stem]
++++
\|u_j\|_G^2
=\|p_j\|_G^2+2p_j^TGe_j+\|e_j\|_G^2
=c_j^2+\|e_j\|_G^2.
++++

The cross term vanishes because stem:[p_j=c_jz] and stem:[z^TGe_j=0]. Also, stem:[\|p_j\|_G^2=c_j^2z^TGz=c_j^2]. This is Pythagoras in the stem:[G] inner product: the squared norm of a snapshot is the sum of the captured and discarded squared norms.

Multiply by the positive weights and sum over snapshots. Define

[stem]
++++
E_{\mathrm{total}}=\sum_{j=1}^m w_j\|u_j\|_G^2,
\qquad
E_{\mathrm{captured}}(z)=\sum_{j=1}^m w_j(z^TGu_j)^2.
++++

Then the reconstruction error is exactly

[stem]
++++
J(z)=\sum_{j=1}^m w_j\|u_j-z(z^TGu_j)\|_G^2
=E_{\mathrm{total}}-E_{\mathrm{captured}}(z).
++++

The total is fixed by the data, metric and weights. Therefore *minimizing the reconstruction error is the same as maximizing the captured energy*. The first mode need not fit any particular snapshot perfectly: it chooses the best compromise over all of them.

Here “energy” means *squared norm in the chosen metric*. In our practical it is the reference diffusion/reaction quadratic form, not the total heat stored in the bar. With stem:[w_j=1/m], these quantities are averages; with stem:[w_j=1], they are sums.


*3. Express this maximization in ordinary Euclidean coordinates*


Factor stem:[G=L^TL], put stem:[W=\operatorname{diag}(w_1,\ldots,w_m)], and define

[stem]
++++
\eta=Lz,\qquad Y=LSW^{1/2},
\qquad y_j=\sqrt{w_j}\,Lu_j.
++++

The vector stem:[\eta] is the same trial direction expressed in energy coordinates; it has ordinary Euclidean length one:

[stem]
++++
\eta^T\eta=z^TL^TLz=z^TGz=1.
++++

Each stem:[y_j] is a weighted snapshot in those coordinates. Its coefficient along stem:[\eta] is

[stem]
++++
\eta^Ty_j=\sqrt{w_j}\,z^TL^TLu_j
=\sqrt{w_j}\,z^TGu_j.
++++

Consequently,

[stem]
++++
E_{\mathrm{captured}}(z)
=\sum_j(\eta^Ty_j)^2
=\|Y^T\eta\|_2^2
=\eta^TYY^T\eta.
++++

Our problem is now to maximize this quadratic form over unit vectors. For any nonzero vector, the associated *Rayleigh quotient* is stem:[\eta^TYY^T\eta/(\eta^T\eta)]. The denominator equals one under our normalization.


*4. Why the maximizer is the first left singular vector*


The SVD stem:[Y=U\Sigma V^T] gives

[stem]
++++
YY^T=U\Sigma\Sigma^TU^T.
++++

Its eigenvectors are the left singular vectors stem:[U_{:,i}], and its eigenvalues are stem:[\sigma_i^2], in decreasing order. Extend them to a full orthonormal basis of stem:[\mathbb R^n], taking zero eigenvalues in any unused directions. Expand a unit candidate as stem:[\eta=\sum_i\xi_i U_{:,i}]. Orthonormality gives stem:[\sum_i\xi_i^2=1], hence

[stem]
++++
\eta^TYY^T\eta
=\sum_i\sigma_i^2\xi_i^2
\leq\sigma_1^2\sum_i\xi_i^2
=\sigma_1^2.
++++

This is a weighted average of the eigenvalues, so it cannot exceed the largest one. Choosing stem:[\eta=U_{:,1}] attains that bound. Return to physical coordinates by solving stem:[Lz_1=U_{:,1}]. We have obtained the first POD mode:

[stem]
++++
z_1=L^{-1}U_{:,1},\qquad
E_{\mathrm{captured}}(z_1)=\sigma_1^2,
\qquad
J(z_1)=\sum_{i>1}\sigma_i^2.
++++

The last equality uses stem:[E_{\mathrm{total}}=\|Y\|_F^2=\sum_i\sigma_i^2]. If the largest singular value is repeated, more than one direction attains the maximum; either sign of a maximizing mode also describes the same line.


*5. Then choose the second direction, and the next ones*


Require stem:[z_2^TGz_1=0] in addition to stem:[z_2^TGz_2=1]. In energy coordinates this means stem:[\eta_2^TU_{:,1}=0], so the coefficient stem:[\xi_1] is zero. The same argument now bounds captured energy by stem:[\sigma_2^2], attained by stem:[U_{:,2}]. Continue under orthogonality to all previously selected directions.

With stem:[Z=[z_1,\ldots,z_r]], the modes are metric-orthonormal. Projection coefficients and reconstruction are

[stem]
++++
c_j=Z^TGu_j,\qquad p_j=Zc_j,
\qquad
E_{\mathrm{captured}}(Z)=\sum_{i=1}^r\sigma_i^2,
\qquad J(Z)=\sum_{i>r}\sigma_i^2.
++++

Now stem:[c_j] is an stem:[r]-component vector. Each additional mode adds an orthogonal component, capturing the next stem:[\sigma_i^2] of energy. The theorem below shows that these first stem:[r] modes also give the best rank-stem:[r] space among all competing spaces, not merely a sequence of good individual directions.

*Connection with PCA.* For centered snapshots in the Euclidean metric, captured energy measures variation around the mean, recovering PCA's variance-maximization principle. For our uncentered thermal snapshots, it measures the full states, including their mean. The projection-error argument works in both cases, but the meaning of the energy differs.

[%collapsible]
.Alternative computation — the method of snapshots
======
[[snapshot-correlation]]

*Method of snapshots: compute modes from correlations*


For a PDE, stem:[n] can be very large while the number of snapshots stem:[m] is modest.
Rather than factoring a large state metric explicitly, compute the small matrix

[stem]
++++
C_s=W^{1/2}S^TGSW^{1/2}=Y^TY\in\mathbb R^{m\times m}.
++++

Its entry stem:[(C_s)_{ij}=\sqrt{w_iw_j}\,u_i^TGu_j] measures similarity of two snapshots in the declared state metric.
It is a Gram/correlation matrix in snapshot coordinates, not the state covariance matrix of centered PCA.
The two are related through the SVD but have different dimensions.
Solve its symmetric eigenproblem with Euclidean-normalized eigenvectors:

[stem]
++++
C_sv_i=\lambda_i v_i,\qquad v_i^Tv_j=\delta_{ij},\qquad
\lambda_i=\sigma_i^2.
++++

For each retained positive eigenvalue, reconstruct the physical mode:

[stem]
++++
z_i=\frac{SW^{1/2}v_i}{\sqrt{\lambda_i}}.
++++

The factor stem:[W^{1/2}] is essential when weights are not all one.
The identity follows by inserting stem:[u_i=Yv_i/\sigma_i] in stem:[z_i=L^{-1}u_i].
It also proves metric orthonormality directly:

[stem]
++++
z_i^TGz_j=\frac{v_i^TC_sv_j}{\sqrt{\lambda_i\lambda_j}}=\delta_{ij}.
++++

No square root of the full metric is needed in this construction: use matrix products with stem:[G], which can remain sparse.
For equal averaging weights stem:[1/m], form stem:[C_s=S^TGS/m] and normalize modes by stem:[\sqrt{m\lambda_i}].
The eigenvalue tail then measures a *mean* squared error, not an unnormalized sum.


*Which computation should be used?*


* If stem:[m\ll n], the stem:[m\times m] snapshot matrix can be much smaller than a state-space covariance matrix.
* If stem:[n\ll m], forming an stem:[m\times m] correlation matrix is not the dimensional saving. Use a direct economy SVD or the smaller transformed state covariance stem:[YY^T].
* Forming a Gram matrix squares the ratio of largest to smallest resolved singular values. A direct SVD generally resolves small modes more reliably; do not divide by an unresolved eigenvalue.

For dense arrays, a tall-matrix SVD costs on the order of stem:[nm^2] when stem:[m\leq n].
Correlation assembly costs products with stem:[G] plus roughly stem:[nm^2] work, followed by an stem:[m\times m] eigensolve; its advantage is the small eigenproblem and avoiding a full metric factorization, not removal of all full-dimensional offline work.

[[snapshot-pod-algorithm]]

*Algorithm — Weighted correlation POD*


Use a numerical eigenvalue threshold first, then select a physical approximation rank.
If the requested tolerance depends on unresolved modes, report that limitation rather than silently promising it has been met.

[.pseudocode]
....
\begin{algorithm}
\caption{POD from weighted snapshot correlations}
\begin{algorithmic}
\INPUT Snapshots $S$; metric $G$; positive weights $W$; rank $r$; eigenvalue threshold $\tau$
\STATE $S_w\leftarrow SW^{1/2}$; $C_s\leftarrow S_w^TGS_w$
\STATE Solve the symmetric eigenproblem and sort eigenpairs in decreasing order
\STATE Check that negative eigenvalues are within declared roundoff tolerance
\STATE $d\leftarrow$ number of eigenvalues greater than $\tau$
\IF{$r>d$}
  \RETURN Requested rank is not numerically resolved
\ENDIF
\FOR{$i=1$ \TO $r$}
  \STATE $z_i\leftarrow S_wv_i/\sqrt{\lambda_i}$
\ENDFOR
\STATE $Z\leftarrow[z_1,\ldots,z_r]$
\STATE Check $Z^TGZ$ and the snapshot projection error
\OUTPUT Basis $Z$ and the resolved eigenvalue spectrum
\end{algorithmic}
\end{algorithm}
....


*Worked computation with a non-diagonal metric*


The following example compares the correlation result with a direct SVD, using unequal weights and a metric that is not diagonal.
It compares projectors because singular vectors may differ by signs.

[source,python]
----
def verify_correlation_example():
    import numpy as np

    S = np.array([[1., 0.], [0., 2.], [1., 1.]])
    G = np.array([[2., 1., 0.], [1., 2., 0.], [0., 0., 3.]])
    w = np.array([0.25, 0.75])
    Sw = S * np.sqrt(w)
    Cs = Sw.T @ G @ Sw
    lam, V = np.linalg.eigh(Cs)
    order = np.argsort(lam)[::-1]
    lam, V = lam[order], V[:, order]
    r = 1
    Zcorr = (Sw @ V[:, :r]) / np.sqrt(lam[:r])
    L = np.linalg.cholesky(G).T
    U, sigma, Vt = np.linalg.svd(L @ Sw, full_matrices=False)
    Zsvd = np.linalg.solve(L, U[:, :r])
    assert np.allclose(lam, sigma**2)
    assert np.allclose(Zcorr.T @ G @ Zcorr, np.eye(r))
    assert np.allclose(Zcorr @ Zcorr.T @ G, Zsvd @ Zsvd.T @ G)
    E = S - Zcorr @ (Zcorr.T @ G @ S)
    error_squared = np.sum(w * np.sum(E * (G @ E), axis=0))
    assert np.isclose(error_squared, np.sum(lam[r:]))
    print("Correlation POD: weighted projection error squared =", error_squared)

verify_correlation_example()

.Centered PCA, affine ROMs and continuous POD
======
[[centered-rom]]

*A centered PCA space needs an affine reduced model*


For unequal sampling weights, the mean minimizing the weighted squared distance to a constant state is

[stem]
++++
\overline{\mathbf u}=\frac{\sum_j w_j\mathbf u_j}{\sum_j w_j}.
++++

Differentiating that quadratic objective gives this formula; the fixed positive definite metric cancels from its normal equations.
Subtract this same mean from every snapshot before the weighted SVD.

For centered modes, reconstruct stem:[\mathbf u_r=\overline{\mathbf u}+Z\mathbf a].
Galerkin testing gives

[stem]
++++
Z^TA(\mu)Z\mathbf a=Z^T\bigl(\mathbf f(\mu)-A(\mu)\overline{\mathbf u}\bigr).
++++

For the course's affine operator, with stem:[A(\mu)=\mu K+M], precompute stem:[Z^TK\overline{\mathbf u}] and stem:[Z^TM\overline{\mathbf u}] in addition to the usual reduced operators.
The output also retains its mean contribution: stem:[s_r=\mathbf l^T\overline{\mathbf u}+(Z^T\mathbf l)^T\mathbf a].
Inserting centered modes into the uncentered equations and forgetting the mean solves a different approximation problem.

The SVD gives projection scores for available snapshots. At a new parameter, Galerkin determines coefficients from the governing equations without requiring a full-order snapshot.
This is the key step from a data reconstruction technique to a predictive ROM.

[[continuous-pod]]

*Supplementary reading — Continuous POD and the meaning of sampling*


A snapshot objective is a finite approximation to a declared objective over parameter space.
Let stem:[\nu] be a measure on stem:[\mathcal P]: it can describe a physical parameter distribution or normalized volume over an operating range.
Assume square-integrability of the solution map:

[stem]
++++
\int_{\mathcal P}\|u_h(\mu)\|_V^2\,d\nu(\mu)<\infty.
++++

The continuous rank-stem:[r] POD problem minimizes

[stem]
++++
\int_{\mathcal P}\|u_h(\mu)-P_{V_r}u_h(\mu)\|_V^2\,d\nu(\mu)
++++

over subspaces of dimension stem:[r], with orthogonal projection in the declared state inner product.
It is an average criterion; minimizing it does not minimize the worst parameterwise error.


*The snapshot operator and its adjoint*


A continuous analogue of the snapshot matrix is the map stem:[T:L^2(\mathcal P,\nu)\to V_h] defined by

[stem]
++++
Tg=\int_{\mathcal P}u_h(\mu)g(\mu)\,d\nu(\mu).
++++

Its adjoint is characterized by stem:[(Tg,v)_V=(g,T^*v)_{L^2(\nu)}].
Substituting the integral yields

[stem]
++++
(T^*v)(\mu)=(u_h(\mu),v)_V.
++++

Thus stem:[T^*] extracts the coefficient function of a state direction over parameter space.
The state correlation operator stem:[\mathcal K=TT^*] is

[stem]
++++
\mathcal Kv=\int_{\mathcal P}u_h(\mu)(u_h(\mu),v)_V\,d\nu(\mu).
++++

It is self-adjoint and positive semidefinite: its quadratic form is the integral of squared coefficients.
It need not be positive definite if the solution family misses a state direction.
Its metric-orthonormal eigenvectors satisfy stem:[\mathcal Kz_i=\lambda_i z_i], with nonnegative decreasing eigenvalues.
The parameter-space operator stem:[\mathcal C=T^*T] instead has kernel stem:[(u_h(\mu),u_h(\mu'))_V], the continuous analogue of snapshot correlations.


*Optimal modes and the continuous tail*


For a positive eigenvalue, define stem:[\psi_i=T^*z_i/\sqrt{\lambda_i}].
Then stem:[\psi_i] are orthonormal in parameter space, stem:[T\psi_i=\sqrt{\lambda_i}z_i], and the state has the expansion

[stem]
++++
u_h(\mu)=\sum_{i=1}^d\sqrt{\lambda_i}z_i\psi_i(\mu)
\quad\text{in }L^2(\mathcal P,\nu;V_h),\qquad d\leq n.
++++

The first stem:[r] eigenvectors minimize the integrated squared projection error, with minimum stem:[\sum_{i>r}\lambda_i].
To see this, for any orthonormal trial directions stem:[b_j], the captured energy is stem:[\sum_{j=1}^r(\mathcal Kb_j,b_j)_V].
Expand each direction in the eigenbasis: as in the discrete POD proof, the largest possible sum is the sum of the first stem:[r] eigenvalues.
Subtract it from the total energy, which is stem:[\sum_i\lambda_i].

The operator formulation expresses the same result using the Hilbert–Schmidt norm:

[stem]
++++
\|T\|_{\mathrm{HS}}^2=\int_{\mathcal P}\|u_h(\mu)\|_V^2\,d\nu(\mu),
\qquad
\min_{\operatorname{rank}(B)\leq r}\|T-B\|_{\mathrm{HS}}^2
=\sum_{i>r}\lambda_i.
++++

The minimizing operator is stem:[P_{V_r}T], the truncated singular expansion (Schmidt approximation).
Here the target space is finite dimensional, so this spectral argument requires no infinite sequence of state modes.
For centered random states with a probability measure, this is also the covariance/Karhunen–Loève interpretation of POD.


*Return to a finite sample: quadrature and probability*


Choose positive quadrature weights and parameter points such that

[stem]
++++
\int_{\mathcal P}F(\mu)\,d\nu(\mu)\approx\sum_{j=1}^m w_j F(\mu_j).
++++

Applying this rule to squared projection errors gives exactly the weighted snapshot objective and correlation matrix stem:[W^{1/2}S^TGSW^{1/2}].
The sampling design and the weights together specify which continuous average is being approximated.

* Independent samples drawn from the desired probability distribution use equal Monte Carlo weights stem:[1/m].
* A uniform grid with a trapezoidal integration rule gives half-weight to the interval endpoints; normalize by interval length for a uniform probability average.
* Equal weights on samples uniform in stem:[t=\log\mu] approximate a log-uniform average. For a uniform physical-parameter average, the substitution stem:[d\mu=e^t dt] introduces the Jacobian into quadrature weights.

Increasing the snapshot count can improve this integral approximation, but the finite-data singular-value tail measures only the discrete training error.
It is not an estimate of quadrature error and does not prove a uniform error bound over the entire parameter domain.
Compare independent validation/test samples and use residual bounds for the reduced solves when their assumptions hold.


*Approximation rank, denoising and compression*


Energy truncation, numerical-rank detection and denoising answer different questions.
When snapshots are noisy, a mode can contain noise energy; retaining a chosen fraction of total energy does not by itself distinguish signal from noise.
A statistical singular-value threshold requires assumptions on the noise distribution and scaling, which need not hold for deterministic PDE discretization errors.
The S1 image-compression analogy is useful: storing a rank-stem:[r] factorization needs approximately stem:[r(n+m+1)] numbers instead of stem:[nm], but small pixel reconstruction error does not certify a physical PDE output.
The course uses noiseless computed snapshots for the basic POD construction and introduces explicit observation noise in the assimilation units.

[%collapsible]
.Additional SVD dimensions and best-rank approximation
======
[[svd-factor-details]]

*Optional SVD details: factor dimensions and identities*


In the full SVD, stem:[U] is stem:[n\times n], stem:[V] is stem:[m\times m] and stem:[\Sigma] is rectangular stem:[n\times m], with nonnegative singular values on its diagonal, ordered decreasingly.
Let stem:[p=\min(n,m)] and stem:[d=\operatorname{rank}(Y)].
Only stem:[d] singular values are positive in exact arithmetic.

[cols="1,2,3",options="header"]
|===
|Representation |Factor dimensions |What is retained?
|Full |stem:[n\times n], stem:[n\times m], stem:[m\times m] |Complete orthogonal coordinate systems, including directions unused by the matrix.
|Economy/thin |stem:[n\times p], stem:[p\times p], stem:[m\times p] |An exact factorization, potentially still including zero singular values.
|Compact |stem:[n\times d], stem:[d\times d], stem:[m\times d] |Only nonzero singular directions; still exact.
|Truncated at rank stem:[r<d] |stem:[n\times r], stem:[r\times r], stem:[m\times r] |An approximation obtained by discarding the smaller singular values.
|===

For positive singular values, multiplying the decomposition and its transpose gives

[stem]
++++
Yv_i=\sigma_i u_i,\qquad Y^Tu_i=\sigma_i v_i,
\qquad Y^TYv_i=\sigma_i^2v_i,\quad YY^Tu_i=\sigma_i^2u_i.
++++

[[svd-low-rank]]

*Truncation, matrix norms and best rank-r approximation*


For stem:[Y_r=\sum_{i=1}^r\sigma_i u_iv_i^T], the two relevant error norms are

[stem]
++++
\|Y-Y_r\|_2=\sigma_{r+1},\qquad
\|Y-Y_r\|_F^2=\sum_{i>r}\sigma_i^2.
++++

The induced 2-norm is the largest amplification of a unit input vector; the Frobenius norm is the square root of the sum of squared entries, equivalently the sum of squared column lengths.
Taking stem:[r=0] gives stem:[\|Y\|_2=\sigma_1] and stem:[\|Y\|_F^2=\sum_i\sigma_i^2].
The truncated SVD minimizes either error over all matrices of rank at most stem:[r] (Eckart–Young optimality).

For the 2-norm lower bound, any rank-stem:[r] competitor stem:[B] has a nonzero null direction in the span of the first stem:[r+1] right singular vectors.
Choose that direction with unit length; then stem:[\|(Y-B)x\|_2=\|Yx\|_2\geq\sigma_{r+1}].
The truncated SVD attains the bound.
For the Frobenius norm, project columns of stem:[Y] onto the range of a competitor first: this cannot increase their error. The captured-energy argument below proves that the leading left singular space gives the smallest such projection error.

The pseudoinverse is stem:[Y^+=V_d\operatorname{diag}(\sigma_i^{-1})U_d^T].
It inverts the action on resolved singular directions and gives the minimum-norm least-squares solution.
For full-column-rank stem:[Y], its 2-norm condition number is stem:[\sigma_1/\sigma_d].
Near-zero singular values make inversion unstable; truncation for numerical rank must be distinguished from truncation for a desired approximation error.

*Pixels are matrix entries*


Let stem:[Y_{ij}\in[0,1]] be the gray level at row stem:[i] and column stem:[j], with 0 black and 1 white.
Each image column is one snapshot in stem:[\mathbb R^h]; here the metric is Euclidean and no mean is subtracted.

[stem]
++++
Y_r=U_r\Sigma_rV_r^T=Z(Z^TY),\qquad
\varepsilon_r=\frac{\|Y-Y_r\|_F}{\|Y\|_F}

++++

[source%dynamic%open,python,fail-on-error=true]

from pathlib import Path
import numpy as np
import matplotlib.pyplot as plt

image_path = Path('melencolia-magic-square.png')
if not image_path.exists():
    image_path = Path('materials/modules/ROOT/attachments/data/melencolia-magic-square.png')
if not image_path.exists():
    raise FileNotFoundError('Download melencolia-magic-square.png beside this notebook.')
Yimg = plt.imread(image_path).astype(np.float64)
assert Yimg.ndim == 2 and 0 <= Yimg.min() <= Yimg.max() <= 1
height, width = Yimg.shape
img_U, img_sigma, img_Vt = np.linalg.svd(Yimg, full_matrices=False)
img_energy = np.sum(img_sigma**2)
# tails[r] is the squared Frobenius error after retaining r modes.
img_tails = np.r_[np.cumsum((img_sigma**2)[::-1])[::-1], 0.0]
img_relative_errors = np.sqrt(img_tails / img_energy)

def image_at_rank(rank):
    if not 0 <= rank <= len(img_sigma):
        raise ValueError('Rank must lie between zero and min(height, width).')
    return (img_U[:, :rank] * img_sigma[:rank]) @ img_Vt[:rank, :]

print(f'Grayscale image: {height} rows x {width} columns')
print(f'Economy SVD: U {img_U.shape}, sigma {img_sigma.shape}, Vt {img_Vt.shape}')

*What is actually compressed?*


Store the three factors, not the dense reconstructed image: stem:[U_r] has stem:[hr] entries, stem:[\Sigma_r] is stored as stem:[r] numbers and stem:[V_r^T] has stem:[rw] entries.
Thus the *fraction of scalar coefficients retained* is stem:[r(h+w+1)/(hw)].
If singular values are absorbed into one factor, two matrices suffice and this becomes stem:[r(h+w)/(hw)], the convention used in the slides.
Neither count is a PNG or JPEG file-size ratio.
In particular, storing float64 factors uses eight bytes per scalar, whereas this source image has one byte per grayscale pixel before PNG encoding.
The last column below makes that distinction explicit and excludes file headers and entropy coding.

[source%dynamic%open,python,fail-on-error=true]
----
print('rank | relative error | retained energy | scalar fraction | float64 / raw uint8 bytes')
for rank in image_ranks:
    Yr = image_at_rank(rank)
    measured = np.linalg.norm(Yimg - Yr, 'fro') / np.linalg.norm(Yimg, 'fro')
    predicted = img_relative_errors[rank]
    assert np.isclose(measured, predicted, rtol=1e-10, atol=1e-12)
    scalar_fraction = rank * (height + width + 1) / (height * width)
    byte_fraction = np.dtype(np.float64).itemsize * scalar_fraction
    retained_energy = 1 - predicted**2
    print(f'{rank:4d} | {measured:14.6%} | {retained_energy:15.6%} | {scalar_fraction:15.4%} | {byte_fraction:10.4f}')
print('Verified: measured reconstruction errors match the singular-value tails.')
