= GEIM: interpolation from linear measurements
:stem: latexmath

Read xref:hyper-reduction/index.adoc[EIM] first. We keep its generating functions stem:[\xi_j], interpolation residuals stem:[r_j], basis functions stem:[\rho_j], coefficients stem:[\gamma_j] and interpolation matrix stem:[\mathbb B_M].
Following the original slides, GEIM replaces the point evaluations stem:[\delta_{t^i}(v)=v(t^i)] by bounded linear measurement functionals stem:[L_i(v)].
The scalar quantity of interest remains stem:[\ell(v)]; it is not the list of sensor readings.
See xref:notation.adoc#interpolation-and-measurements[the common notation] for the complete correspondence.

== From EIM to GEIM: change the measurements, keep the interpolation principle

[cols="1,1,1",options="header"]
|===
|Object |EIM |GEIM
|Measurement |stem:[\delta_{t^i}(v)=v(t^i)] |stem:[L_i(v)]
|Basis functions |stem:[\rho_1,\ldots,\rho_M] |stem:[\rho_1,\ldots,\rho_M]
|Interpolation matrix |stem:[(\mathbb B_M)_{ij}=\rho_j(t^i)] |stem:[(\mathbb B_M)_{ij}=L_i(\rho_j)]
|Right-hand side |stem:[g(t^i;\mu)] |stem:[y_i=L_i(u)]
|Coefficients |stem:[\mathbb B_M\gamma(\mu)=\mathbf g_M(\mu)] |stem:[\mathbb B_M\gamma(y)=y]
|===

The generalized interpolant is

[stem]
++++
I_M^L u=\sum_{j=1}^M\gamma_j(y)\rho_j,\qquad
L_i(I_M^L u)=L_i(u),\quad i=1,\ldots,M.
++++

The superscript stem:[L] identifies generalized measurements, while stem:[x] in stem:[I_M^x] identifies the point interpolation of EIM. The construction is otherwise the same kind of hierarchical interpolation.
In EIM the parameter is supplied so that the selected function values can be evaluated. In GEIM the parameter or full state may be unknown: the online inputs are the measured values stem:[y], not the hidden true field.
This is state reconstruction, not identification of a conductivity parameter by nonlinear least squares.

== Declare and normalize the sensor dictionary

Fix the state inner product stem:[(\cdot,\cdot)_X] and a dictionary stem:[\Sigma_L\subset(X^{\mathcal N})'] of candidate sensors.
Examples are localized averages and weighted integrals. For every candidate, specify its units and normalization before comparing responses.
The practical uses normalized averages: every sensor returns one on the constant unit state.
This physical normalization need not be unit normalization in the dual norm.

In coordinates, define a sensor by its coefficient vector stem:[h_s], and stack its transpose as a row of the dictionary matrix stem:[H_\Sigma]:

[stem]
++++
L_s(v)=h_s^T\mathbf v,\qquad
\mathbf y=H_M\mathbf u+\boldsymbol\varepsilon,\qquad
G=G^T>0,\quad H_M\in\mathbb R^{M\times\mathcal N}.
++++

Here stem:[H_M] contains only the selected rows, and stem:[\varepsilon] is measurement noise. In KF and EnKF the same observation operator is written stem:[H_k] when it depends on the time step.
The xref:foundations/riesz.adoc[Riesz representation theorem] gives the representative stem:[w_s] of stem:[L_s]:

[stem]
++++
G\mathbf w_s=h_s,\qquad
L_s(v)=(w_s,v)_X=\mathbf w_s^TG\mathbf v,\qquad
\|L_s\|_{(X^{\mathcal N})'}=\sqrt{h_s^T\mathbf w_s}.
++++

A row of stem:[H_\Sigma] contains functional coefficients; it is not a Riesz representative. The stem:[\rho_j] are GEIM interpolation functions, not Riesz representatives either.
For an integral sensor stem:[L_s(v)=\int_\Omega\psi_s v] in an stem:[L^2] metric, boundedness follows from Cauchy–Schwarz with stem:[\|L_s\|\leq\|\psi_s\|_{L^2}].
Point evaluation is not defined on stem:[L^2] equivalence classes. See the xref:foundations/riesz.adoc#function-space-example[average and point-sensor examples] before transferring a discrete sensor to a continuous function space.
Rescaling a sensor also rescales its noise: changing numerical entries alone does not create more information.

== Generating function, interpolation residual and next sensor

Start from the same full-order state snapshots used for reduction. At step stem:[m], compute their generalized interpolation residuals

[stem]
++++
e_m(\mu)=u^{\mathcal N}(\mu)-I_m^L u^{\mathcal N}(\mu).
++++

The practical searches a finite collection of parameter/sensor pairs:

[stem]
++++
(\mu^{m+1}_{\mathrm{GEIM}},L_{m+1})\in
\operatorname*{arg\,max}_{\mu\in D_{\mu,\mathrm{train}},\,L\in\Sigma_L}|L(e_m(\mu))|.
++++

Then define the generating function, its residual and the normalized new basis function:

[stem]
++++
\xi_{m+1}=u^{\mathcal N}(\mu^{m+1}_{\mathrm{GEIM}}),\qquad
r_{m+1}=\xi_{m+1}-I_m^L\xi_{m+1},\qquad
\rho_{m+1}=\frac{r_{m+1}}{L_{m+1}(r_{m+1})}.
++++

As in EIM, divide by the *signed* selected value. Provided it is nonzero,

[stem]
++++
L_i(\rho_j)=0\ (i<j),\qquad L_j(\rho_j)=1.
++++

Thus stem:[\mathbb B_m] is lower triangular with unit diagonal, and the interpolation space stem:[X_m^{\mathrm{GEIM}}=\operatorname{span}\{\rho_1,\ldots,\rho_m\}] is hierarchical.
The GEIM space is distinct from the Galerkin background space stem:[X_N]; their dimensions stem:[m] and stem:[N] need not agree.
The maximum sensor response is a *dictionary seminorm*. Without a norming assumption on the dictionary, it is not the state norm: zero response may mean a nonzero residual is invisible to every candidate sensor.

[[geim-algorithm]]
=== Algorithm — GEIM on the training fields and sensor dictionary

Let stem:[F] contain the training snapshots, stem:[\mathcal R] the sampled interpolation functions, and stem:[p] the selected sensor indices. These are `S`, `rho` and `chosen` in the notebook.

[.pseudocode]
....
\begin{algorithm}
\caption{GEIM: generating functions and generalized measurements}
\begin{algorithmic}
\INPUT Training fields $F$; normalized dictionary $H_\Sigma$; response tolerance $\varepsilon_{\mathrm{GEIM}}$; budget $M_{\max}$
\STATE $\mathcal R\leftarrow[\,]$; $p\leftarrow[\,]$; $m\leftarrow0$
\WHILE{true}
  \IF{$m=0$}
    \STATE $E\leftarrow F$
  \ELSE
    \STATE $H_m\leftarrow H_\Sigma[p,:]$; $\mathbb B_m\leftarrow H_m\mathcal R$
    \STATE Solve $\mathbb B_m C=H_mF$; $E\leftarrow F-\mathcal R C$
  \ENDIF
  \STATE $D\leftarrow H_\Sigma E$; $(i_*,j_*)\leftarrow\operatorname{argmax}_{i,j}|D_{ij}|$
  \IF{$|D_{i_*j_*}|\leq\varepsilon_{\mathrm{GEIM}}$}
    \RETURN Basis and sensors; dictionary response tolerance met
  \ENDIF
  \IF{$m=M_{\max}$}
    \RETURN Basis and sensors; dimension budget reached
  \ENDIF
  \STATE $\xi_{m+1}\leftarrow F_{:,j_*}$; $r_{m+1}\leftarrow E_{:,j_*}$; $L_{m+1}\leftarrow (H_\Sigma)_{i_*,:}$
  \STATE $\rho_{m+1}\leftarrow r_{m+1}/L_{m+1}(r_{m+1})$
  \STATE Append $\rho_{m+1}$ to $\mathcal R$ and $i_*$ to $p$; $m\leftarrow m+1$
\ENDWHILE
\end{algorithmic}
\end{algorithm}
....

== Online reconstruction and Python correspondence

For the final size stem:[M], form stem:[\mathbb B_M=H_M\mathcal R_M] offline. Given new measurements, solve

[stem]
++++
\mathbb B_M\gamma(y)=y,\qquad \widehat{\mathbf u}=\mathcal R_M\gamma(y).
++++

[cols="1,2",options="header"]
|===
|Mathematical object |Notebook object
|stem:[u^{\mathcal N}(\mu_j)] |`S[:, j] = field(...)`: a training state
|stem:[H_\Sigma], stem:[L_s] |`Hdict`, one functional per row
|stem:[\rho_j], stem:[\mathcal R_M] |`rho[:, j]`, `rho`
|Selected stem:[L_i], stem:[H_M] |`Hdict[chosen]`, stored as `H`
|stem:[\mathbb B_M] |`B_geim = H @ rho`
|stem:[\gamma(y)] |`gamma = np.linalg.solve(B_geim, y)`
|===

== Approximation error and measurement noise

Define the data-to-state map stem:[D_M=\mathcal R_M\mathbb B_M^{-1}] by a linear solve. For stem:[G=LL^T], the noise amplification is

[stem]
++++
\|\widehat u(y+\varepsilon)-\widehat u(y)\|_X
\leq\|L^TD_M\|_2\|\varepsilon\|_2.
++++

The upper-case Cholesky factor stem:[L] is a matrix; the stem:[L_i] are measurement functionals. The indices and declared types distinguish them.
The largest singular value of stem:[L^TD_M] computes this norm. For noise stem:[\varepsilon=C_\varepsilon\zeta] with covariance stem:[C_\varepsilon C_\varepsilon^T], standardized noise is amplified by stem:[\|L^TD_MC_\varepsilon\|_2].
Noiseless interpolation is the state-to-state map stem:[I_M^L=D_MH_M]. It reproduces every stem:[v\in X_M^{\mathrm{GEIM}}], hence

[stem]
++++
u-I_M^L u=(I-I_M^L)(u-v),\qquad
\|u-I_M^L u\|_X\leq
(1+\|I_M^L\|_{X\to X})\inf_{v\in X_M^{\mathrm{GEIM}}}\|u-v\|_X.
++++

The state-to-state operator norm here is different from the measurement-noise amplification norm above. More interpolation conditions may worsen noise sensitivity.
Oversampled least squares and regularization explicitly change the reconstruction rule.

== Continue to PBDW and sequential assimilation

GEIM infers coefficients of its interpolation basis from measurements. PBDW instead combines a Galerkin/POD background basis stem:[Z] with a correction in the sensor Riesz space.
The PBDW chapter denotes the Riesz matrix by stem:[W], defined by stem:[GW=H^T]. Neither stem:[W] nor stem:[Z] is the GEIM interpolation matrix stem:[\mathcal R_M].
KF and EnKF retain stem:[y=Hu+\varepsilon] and add a time-dependent forecast and covariance update.
